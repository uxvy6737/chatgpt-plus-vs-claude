## 额度：两边的计费逻辑根本不是一回事

这是最容易忽略、也最容易导致退订的一节。

ChatGPT 按消息条数算：免费版每 5 小时 10 条 GPT-5.5；Plus 和 Go 每 3 小时 160 条，用完之后对话会回落到 mini 版本；Plus 和 Business 用户可以手动切到 GPT-5.5 Thinking，每周上限 3000 条。

Claude 按时间窗口算：Pro 是 5 小时会话上限，加上一层覆盖所有模型的每周额度，从会话开始算起 7 天后重置。这两个数字在设置的 Usage 页面里都能看到。

差别体现在使用手感上。多轮来回的对话会一条一条吃掉 ChatGPT 的 160 条配额；Claude 记的是算力消耗，几次塞满长上下文的重会话，可能比很多次短问答更费额度。

- 一阵一阵高强度地用，中间大量空白 —— Claude Pro 的滚动窗口更友好
- 每天稳定几十条，节奏均匀 —— ChatGPT Plus 的按条计数更好预估

关于"谁给得更多"，两份公开测算的结论正好相反。SemiAnalysis 测出的结果是，Claude Pro 的 $20 档每月约提供 29 亿 token，ChatGPT 的 $20 档约 10 亿，折算成 API 等值价值，Anthropic 大约高出 5 倍。Artificial Analysis 换了个算法，按"完成一个任务需要多少 API 成本"来算：GPT-6.1 Sol 约 $0.72，Claude Opus 5.5 约 $5.98，结论反过来了。

> token 不是工作量单位。两个模型做同一件事，消耗的 token 可能差好几倍，所以"谁给得多"和"谁更划算"是两个问题，两个答案都不算错。

## 功能：一个偏工具箱，一个偏工作台

ChatGPT Plus 的定位是"什么都有一点"：原生图像生成、语音模式、Canvas、Advanced Data Analysis、Vision、ChatGPT Agent、Deep Research，还有 Sora 视频预览。需要注意的是，OpenAI 在 2026 年 9 月宣布要下线自定义 GPT，迁移到插件体系，所以"自定义 GPT 生态"已经不再是长期优势。

Claude Pro 的定位是"把活儿干完"：Claude Code、Claude Cowork、不限数量的 Projects、Microsoft 365 和 Outlook 集成、MCP 连接器（可以接 Gmail、日历、Drive、Slack 以及远程 MCP 服务）。它没有原生图像和视频生成，视觉类的产出走的是 Claude Design。

一句话概括：要在对话里出图、出视频、听语音，只有 ChatGPT 能做；要跑代码、跑文档流程，Claude 在这份订阅里捆得更多，年付还更便宜。

## 使用前该知道的三件事

**一、需要提交账号的登录状态信息。** 这不是可选项，平台靠它自动完成订阅和后续月份的续订，不用你的密码，但它确实能看到你账号的登录态。介意的人应该直接用官方渠道。

**二、续费不保证每月自动成功。** 公开的实测记录里，2026 年 7 月、8 月、9 月都出现过续费失败、原账单作废、部分退款、需要重新下单或点"修复订阅"的情况。有一次从发现问题到修复完成只用了十几分钟，也有一次等客服超过一小时。钱最终退了，但中间会出现订阅状态和账单状态不同步的空档，ChatGPT 界面可能先显示免费版，过一阵才恢复 Plus 权益。判断是否真的恢复，要同时看三处：平台的订阅到期日、官方账单里有没有新的已支付发票、以及功能界面是否回到付费状态。

**三、价格高于官方原价。** 你省下的是开卡费、手续费和折腾时间，不是美元本身。如果目标只是"越便宜越好"，这不是最省钱的路子。

## 常见问题

**两个都订会浪费吗？**
看使用频率。每天在两个工具之间来回切的人，两份订阅是效率；一周只打开两次的人，第二份基本是白交。多数人一个主力加一个免费版就够用。

**先订哪个更不容易后悔？**
如果你说不清自己主要拿 AI 做什么，ChatGPT Plus 覆盖面更宽，后悔概率低一些。如果你已经有明确的工作流，比如写代码或者做长文分析，Claude Pro 的针对性更强，年付还便宜。

**合租和独立订阅差别有多大？**
合租是共享额度，价格低很多（ChatGPT Plus 合租 $7.99/月，Claude Pro 合租 $14.99/月），公开资料显示对话记录是隔离的，但额度池是共用的。适合轻量使用和试水，不适合每天高强度跑。

按公开记录算，ChatGPT Plus 三个月 $66.09，折合每月约 $22.03，比单月 $24.99 便宜约 $3/月。但它不是把三个月一次付给 OpenAI，而是后续月份仍要按月完成续订，所以会存在上文说的续费环节风险。便宜是真的，需要偶尔盯一下状态也是真的。

**如果订完发现选错了呢？**
这就是为什么建议第一份先买 1 个月。一个月的成本是 25 美元上下，比赌一个季度划算。用满一个月，你的真实使用数据比任何对比文章都准。
